# 页尾 SplitText 与联系信息精简设计

## 目标

让页尾收尾文案在进入视口时以克制的逐字动画出现，并精简联系信息区域的视觉装饰。

## 文案动画

- 文案保持“感谢您的观看，期待您的回复。”，不修改文字内容。
- 使用 React Bits `SplitText` 组件并以 `h2` 标签渲染。
- 按字符拆分，从下方轻微位移并淡入；每个字符间隔短，整体节奏连贯。
- 动画仅在页尾首次进入视口时触发一次。
- 用户启用 `prefers-reduced-motion: reduce` 时直接展示完整文字，不执行位移动画。
- 保持现有左对齐、两行结构、字号和响应式规则。

## 联系信息精简

- 去掉联系信息区域上、下两根横线。
- 去掉邮箱和电话号码后的 `↗` 箭头。
- 邮箱和电话继续分别使用 `mailto:` 与 `tel:` 链接。
- 保留邮箱、电话、微信的“复制”按钮及现有悬停交互。
- 微信展示方式保持不变。

## 技术范围

- 新增独立 `SplitText` 客户端组件。
- 使用项目已有的 `gsap`，并增加 React 集成依赖 `@gsap/react`。
- 修改页尾渲染、联系信息组件、页尾 CSS 和结构测试。
- 不修改其他模块或联系信息内容。

## 验收

- 页尾标题包含 SplitText 标识并仍以 `h2` 语义渲染。
- 邮箱、电话链接不再包含箭头。
- 联系信息区域不再包含上下边框。
- 三个复制按钮继续存在。
- 完整测试和构建通过。
