# 精选项目彩色自动滚动设计

## 目标

让精选项目始终以原始彩色展示，并通过无缝横向自动滚动提高项目曝光度，同时保留用户主动浏览能力。

## 展示

- 移除 ChromaGrid 的灰度遮罩和鼠标位置灰度过渡。
- 保留卡片现有图片、渐变背景、边框高光和文案结构。
- 隐藏横向容器的原生滚动条，但保持容器可滚动。

## 自动滚动

- 将五个项目渲染为连续的两组，第二组仅用于实现无缝循环，并从辅助技术中隐藏重复内容。
- 使用 `requestAnimationFrame` 驱动容器从右向左缓慢滚动；到达第一组末尾时无感回到对应位置。
- 鼠标悬停、键盘焦点进入、指针按下或用户滚轮操作时暂停；交互结束后继续。
- 触摸设备继续支持原生横向滑动。
- 用户系统启用 `prefers-reduced-motion: reduce` 时不启动自动滚动。

## 范围

- 仅修改 `ChromaGrid` 组件、对应 CSS 和结构测试。
- 不修改项目数据、项目顺序、图片文件或其他页面模块。

## 验收

- 页面包含自动滚动标识，并渲染两组项目卡片。
- 对辅助技术只暴露第一组五个项目，重复组标记为隐藏。
- 灰度滤镜不再存在，滚动条在主流浏览器中不可见。
- 手动滚动、暂停交互和减少动态效果逻辑保留。
- 现有测试和项目构建通过。
