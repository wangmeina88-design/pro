# 精选项目二级详情页设计

## 目标

为首页 5 个精选项目建立可点击进入的独立详情页，完整展示对应项目 PDF 的视觉内容，并兼顾桌面端和移动端浏览。

## 项目映射

| 首页项目 | 路由 | 来源 PDF |
| --- | --- | --- |
| AI 赋能产品体验 | `/projects/ai-experience` | `ai流程详情.pdf` |
| 星海情绪助手 | `/projects/starry-miracle` | `星海详情.pdf` |
| 吴歌陪伴体验升级 | `/projects/wuge-miracle` | `吴歌详情.pdf` |
| APa 网校系统 | `/projects/apa-school` | `apa详情.pdf` |
| 复华财富 | `/projects/forise-wealth` | `复华资产详情页.pdf` |

## 页面结构

- 统一使用一个动态项目详情模板，通过 slug 读取项目数据。
- 顶部保留 WMN 品牌、返回作品列表和返回首页入口。
- 首屏显示项目编号、中文名称和英文类型。
- 主体直接嵌入对应 PDF，保留 PDF 阅读器的翻页、缩放和下载能力。
- 底部提供上一个项目、下一个项目和返回精选项目。
- 未知 slug 返回 404，不展示空页面。

## PDF 素材处理

- 原始 PDF 保持不变，并各复制一份到公开素材目录。
- 页面通过内嵌 PDF 阅读器直接展示，不进行 66 页图片转换。
- 阅读器下方提供“单独打开 PDF”链接，作为浏览器不支持内嵌 PDF 时的备用入口。

## 首页跳转

- 为 5 个项目数据增加对应的内部 URL。
- 项目卡片点击后在当前标签页进入详情，不打开新标签页。
- 保留自动横向滚动；用户悬停或交互时继续暂停。
- 卡片可通过键盘聚焦，并支持 Enter 键进入详情。

## 响应式与视觉

- 详情页沿用主站暗色背景、字体、蓝紫强调色和页面留白。
- PDF 阅读器使用完整内容宽度和足够的视口高度。
- 桌面端使用主站内容宽度；移动端减小边距并保持图片完整。
- 支持 `prefers-reduced-motion`，不增加强制滚动或入场动画。

## 验收

- 5 张首页项目卡片分别链接到正确路由。
- 5 个路由均返回 200，错误 slug 返回 404。
- 每个详情页内嵌正确的项目 PDF，并提供单独打开入口。
- 上一个、下一个和返回链接正确。
- 完整测试和生产构建通过。
