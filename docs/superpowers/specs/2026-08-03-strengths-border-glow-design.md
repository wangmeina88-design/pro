# 个人优势 BorderGlow 设计

## 目标

将个人优势模块改为四张独立的边缘感应高光卡片，增强暗色科技感，同时保持克制。

## 内容

- 四张卡片的编号、标题、说明文案、顺序完全不变。
- 不新增、删减或改写任何个人优势文案。

## 视觉与交互

- 卡片由连体细线网格改为四张独立卡片，间距 16px。
- 卡片圆角 20px，使用深灰黑背景与低对比静态边框。
- 高光颜色使用蓝、紫、青渐变，并采用附件原版的七层网格渐变分布。
- 完整保留原版三层效果：彩色渐变边框、边缘背景填充、外部多级发光。
- 完整保留原版方向锥形遮罩与多重径向遮罩；鼠标靠近卡片边缘时，高光根据指针方向出现并移动。
- 不启用自动入场扫光，避免四张卡片同时发光。
- PC 端保持四列，移动端保持两列。

## 范围

- `BorderGlow` 客户端组件和局部 CSS 使用用户附件中的完整源码效果，不使用简化版。
- 仅替换个人优势卡片容器，不修改其他模块。
- 保留当前分支已完成的页尾 SplitText 和联系信息精简改动。

## 验收

- 页面渲染四个 BorderGlow 容器。
- 组件 CSS 包含完整的渐变边框、背景填充和外发光三层效果。
- 四组原始个人优势文案全部存在且顺序不变。
- 组件不启用自动扫光。
- 响应式列数保持桌面四列、移动端两列。
- 完整测试与构建通过。
