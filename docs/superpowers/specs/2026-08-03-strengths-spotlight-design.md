# 个人优势 SpotlightCard 交互设计

## 目标

为“个人优势”模块的四张能力卡片增加随鼠标位置移动的柔和聚光效果，在不改变现有内容结构和页面节奏的前提下增强反馈与科技感。

## 交互

- 每张能力卡片独立响应指针移动，并以指针在卡片中的坐标作为径向渐变中心。
- 聚光采用低饱和蓝紫色，悬停时渐显，移出后自然消失。
- 键盘焦点进入卡片内容时同样显示聚光，以保持可访问性。
- 触摸设备不依赖悬停反馈，继续显示稳定的静态卡片。

## 视觉

- 保留原有四列/移动端两列布局、编号、标题、说明文案和卡片尺寸。
- 聚光层不接收点击事件，也不遮挡文字。
- 继续使用现有暗色背景与细分隔线；不加入位移、缩放或强霓虹边框。

## 实现边界

- 新增独立的 `SpotlightCard` 客户端组件及其局部 CSS。
- “个人优势”数据和渲染顺序保持不变，仅将每个原生卡片替换为该组件。
- 不引入第三方依赖，不修改经历、项目、页尾或导航模块。

## 验收

- 服务端渲染结果包含四个 SpotlightCard 容器。
- 每张卡片仍完整显示原有编号、标题和说明。
- 项目构建成功，现有回归测试与新增结构测试全部通过。
