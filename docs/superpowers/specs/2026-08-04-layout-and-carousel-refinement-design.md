# 作品集布局与轮播优化设计

## 目标

统一主页与项目详情页的内容边界，优化首屏人物与文案关系，强化个人优势编号层级，按指定顺序展示五个不重复项目并实现无缝左移轮播，同时修正页尾信息对齐。

## 设计

- 所有顶部导航使用与 `.section-shell` 相同的最大宽度和左右留白，导航背景仍铺满屏幕。
- 首屏使用用户新增的无水印 `intro.mp4`。桌面端视频画面略向右定位，标题限制在左侧约 56% 宽度并降低字号；移动端恢复居中裁切和适配字号。
- 优势卡片编号放大为低对比度、细描边、轻微倾斜的装饰数字，不改变现有文案与 BorderGlow 动效。
- 项目数据顺序固定为：吴歌、星海、APa、复华、AI。每个项目在语义主列表中只出现一次；第二组仅作为 `aria-hidden` 的无缝循环副本。轨道持续向左滚动，悬停、聚焦和拖动时暂停，减少动态偏好时停止自动播放。
- 页尾继续使用统一内容壳，移除首个联系方式的额外内边距，使邮箱和版权严格共用左边界。

## 验收

- 主页和详情页导航内层均使用 `.section-shell`。
- HTML 主项目组按指定顺序输出五个项目。
- 自动轮播、隐藏滚动条、详情链接和键盘访问继续有效。
- 新视频存在于 `public/media/intro.mp4`。
- 测试、构建与 lint 无错误。
