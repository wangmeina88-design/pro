# 个人站资源与全屏交互更新设计

## 目标

在不改变现有文案、项目顺序和模块内部排版的前提下，完成三项更新：

1. 用用户新压缩的五张精选项目封面替换仓库中的大图。
2. 将首页首屏的 SplashCursor 流体鼠标效果扩展到整个页面。
3. 将首页各主要模块之间的纵向间距统一缩小约 25%。

## 全屏流体效果

保留现有 SplashCursor 实现，将画布从 Hero 内部元素调整为视口固定层：

- 覆盖整个视口并随页面滚动持续显示。
- 使用 `pointer-events: none`，不拦截导航、项目卡片、复制按钮等操作。
- 画布层级低于导航和主要内容，采用现有的克制透明度与混合模式。
- `prefers-reduced-motion: reduce` 时关闭。
- 无精确指针的触屏设备不加载持续交互，避免移动端性能问题。

## 模块间距

统一收紧首页主要区块的外部纵向留白，不调整卡片内部间距：

- PC 端各主要模块顶部间距缩小约 25%。
- 项目区与联系区之间的额外空白同步缩小。
- 移动端采用同方向但更温和的缩减，保证标题与内容仍有清晰层级。
- Hero 仍保持完整首屏高度，避免影响视频视觉展示。

## 验证标准

- 五张项目封面内容与项目名称一一对应，尺寸显著小于原文件。
- 鼠标流体效果在 Hero、个人优势、个人经历、精选项目和联系区均可见。
- 全屏效果不阻挡任何点击、悬浮、复制和横向项目滚动。
- 页面模块间距比当前版本更紧凑，PC 与移动端无内容重叠。
- 自动化测试、代码检查和 Cloudflare 生产构建通过。
- 仅提交设计说明、五张封面和完成上述交互所需的代码改动。
